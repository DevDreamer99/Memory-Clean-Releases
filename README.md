# Memory Clean

Memory Clean for macOS: keeps an eye on your Mac's memory from the menu bar and frees it with one click.

## Download

Get the latest version from the [**Releases**](https://github.com/DevDreamer99/Memory-Clean-Releases/releases/latest) page, open the DMG and drag **Memory Clean** into **Applications**.

The app checks this page once a day and tells you when a new version is available.

## Features

- Available memory, swap and memory pressure, live in the menu bar
- Clean and Extreme Clean, plus automatic cleaning below a threshold
- Memory hogs and inactive apps, with notifications
- English, Italiano, Français, Deutsch, Español, 简体中文

## Requirements

macOS 27 or later. Signed with a Developer ID and notarized by Apple.
